02 / System design

How it works

GPS device → Ordered upsert → PostgreSQL → Map

Correctness boundary

A higher sequence number wins atomically. Duplicates and stale updates cannot overwrite newer locations.

Path to scale

Partition historical telemetry by time. Use a broker for fanout and keep latest-position reads separate from route analytics.

Demo scope

Synthetic vehicles; two-second polling. Device identity, historical routes and WebSocket fanout are roadmap items.
